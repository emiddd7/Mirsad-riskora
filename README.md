# Mirsad Riskora — GitHub working prototype

مرصد رسكاورا — نسخة GitHub محسّنة بصريًا ووظيفيًا.

## التشغيل
1. ارفع `index.html` و`style.css` و`app.js` إلى المستودع.
2. من GitHub: Settings → Pages → Deploy from branch → `main` / root.
3. افتح رابط GitHub Pages.

## الدخول التجريبي
- Username: `demo`
- Password: `123456`

## ملاحظات
- المشروع Prototype تعليمي وليس منتج تأمين مرخصًا.
- البيانات المستخدمة داخل الواجهة تجريبية.
- الدفع تجريبي وليس بوابة دفع حقيقية.
- نموذج التعويض بارامتري: يعتمد على تحقق المؤشر المحدد وليس على إثبات الضرر كشرط أساسي.
- يتم حفظ الاختيارات وحالة الوثيقة محليًا عبر `localStorage`.
